### A note on GSAP

GSAP is **not** MIT. The standard licence is free for the overwhelming majority
of uses, including commercial sites and this one, but it is not an open-source
licence and it does place conditions on one specific case: charging multiple
customers for a product that includes GSAP requires a Club GreenSock
commercial licence.

This project uses exactly one GSAP feature — `SplitText`, to break a heading
into per-character spans for the masked reveals. If that licence is awkward for
your use, `SplitText` is the only import to replace; nothing else in the code
touches GSAP.
